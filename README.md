# AWS Serverless REST API with CRUD Operations

## Project Overview

This project demonstrates the development of a Serverless REST API using Amazon Web Services (AWS).

The objective is to create an API that supports CRUD (Create, Read, Update and Delete) operations and demonstrates how serverless architecture works.

## Key Features

- Create records using POST requests.
- Retrieve records using GET requests.
- Update records using PUT requests.
- Delete records using DELETE requests.

## AWS Services

- Amazon API Gateway
- AWS Lambda
- AWS IAM
- Amazon CloudWatch

## Technologies

- Python
- REST API
- AWS Services

## Project Architecture

Client → API Gateway → AWS Lambda → Backend Processing

## Project Learning Outcomes

- Understanding serverless architecture.
- Creating and configuring REST API endpoints.
- Implementing CRUD operations.
- Configuring AWS permissions.
- Testing API requests and responses.
